Panduan Instalasi

Sebelum menggunakan script bot WhatsApp, pastikan untuk mengikuti panduan berikut:

  • Persyaratan Sistem: Pastikan Node.js/Python sudah terinstall di perangkat Anda
  • Dependencies: Install semua dependencies yang diperlukan dengan perintah npm install atau pip install
  • Konfigurasi: Edit file config sesuai dengan kebutuhan Anda
  • Jalankan Bot: Gunakan perintah npm start atau python main.py untuk menjalankan bot

Persyaratan Sistem:

  • Node.js v16+ (untuk script Node.js)
  • Python 3.8+ (untuk script Python)
  • RAM Minimal 2GB
  • Koneksi Internet Stabil

Peringatan: Penggunaan bot WhatsApp mungkin melanggar ketentuan layanan WhatsApp. Gunakan dengan bijak dan bertanggung jawab. Kami tidak bertanggung jawab atas segala bentuk banned akun.
